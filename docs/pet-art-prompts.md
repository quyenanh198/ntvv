# Farm-owned pet artwork

Built-in imagegen created six static game pet sprites. Transparent originals are saved in `asset/source_pets/v3/`; 128px game exports are in `public/assets/pets-v3/`. The rabbit reuses `public/assets/art/rabbit_v3.png` and its existing source in `asset/source_animals/rabbit_v3.png`. The personalization shop and owner/visitor gallery share these previews. The generated inventory records pet coverage separately from decorations and products.
