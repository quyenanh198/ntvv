# Five-session player study

Run five first-session observations and at least one returning-session observation before the release gate. Use a staging build and a fresh account for each first session. Do not use live accounts or record personal chat content. Ask permission to observe and take notes; keep notes under anonymous participant numbers.

## First session (15 minutes)

1. Say: “Please play this farm as you normally would. Tell me what you expect when you tap something. I will not give hints unless you are stuck for two minutes.”
2. Start a timer when the farm first becomes interactive. Record the first action and when the player plants, waters, harvests, opens inventory, and completes a sale or delivery.
3. Ask the player to “earn some gold from your farm.” Do not point to controls. Note where they pause, misread a cost or reward, or try a disabled action.
4. If no sale occurs by ten minutes, ask what the player expected to do next. Then offer one hint and record whether that resolves the issue.
5. Ask: “What would you do when you come back tomorrow?” and “Which part was confusing?”

## Returning session (5 minutes)

Use a low-level account with a ready crop, a growing crop needing water, an empty plot, and one available order. Begin timing when the farm becomes interactive. Ask the player to do something useful; record the first action and time to it. Then ask them to find the next goal and to explain the expected reward for an order. Repeat at a phone width first; check desktop or keyboard flow where relevant.

## Note sheet per participant

| Field | Record |
| --- | --- |
| Participant code / device / viewport | Anonymous code and setup only |
| First plant / harvest / sale times | Minutes and seconds from interactive farm |
| Returning first productive action | Action and seconds |
| Confusion or blocked step | Exact control or game state, player’s expectation, whether a hint was needed |
| Accessibility or visual issue | Text, icon, focus, motion, touch target, or screen-reader observation |
| Quote | Short quote with no name or chat content |

After the fifth first session, group repeated failures, name the top three, and link each to a proposed fix. Re-run the affected task after changes. Report the observed count beside the staged funnel counts; do not treat five sessions as a retention estimate.
